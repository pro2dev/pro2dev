# 🔐 Privacy Policy — MentorAI (Discord Bot)
Ultimo aggiornamento: 18 ottobre 2025 Autore: Pro2Dev Team

**MentorAI è progettato per rispettare la privacy degli utenti e operare in conformità con le API di Discord.**

# 📊 Dati raccolti
MentorAI non raccoglie, conserva né condivide dati personali degli utenti. Tutte le interazioni avvengono in tempo reale e sono limitate al contesto del server Discord.

# 🧠 Dati elaborati
Comandi slash e messaggi diretti al bot

- Informazioni pubbliche del server (ruoli, nickname, status)
- Eventuali configurazioni modulari definite dagli amministratori

# 🚫 Dati non trattati
Nessun tracciamento esterno

- Nessun salvataggio di cronologia utente
- Nessuna analisi comportamentale o profilazione

# 🛡️ Sicurezza
MentorAI opera esclusivamente all’interno dell’ambiente Discord. Non comunica con database esterni né archivia contenuti.

# 📬 Contatti
Per domande o segnalazioni, contatta il team Pro2Dev tramite GitHub Issues o Discord.
